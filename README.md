# Resonancias

Una idea para habitar el día. Una lectura cada día, sin prisas y sin ruido.

Sitio publicado en https://resonancias.lama.lat, un proyecto del Laboratorio de Mediaciones Algorítmicas (LAMA) de la Universidad del Valle (Cali, Colombia).

Este repositorio contiene solo la versión publicada. Se genera desde la carpeta de trabajo con `herramientas/preparar_publicacion.py --base https://resonancias.lama.lat/` y se copia aquí con `herramientas/sincronizar_sitio.sh`; no se edita a mano.
